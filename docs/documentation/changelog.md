## [2.3.0167] - 2025-12-13

### Добавлено

- ✅ **Автоматическое управление версией** - версия увеличивается при каждой сборке
- ✅ **Пауза при потере жизни** - игра ставится на паузу, можно изменить скорость мяча
- ✅ **Автоматическая очистка лог-файлов** - старые логи удаляются при запуске
- ✅ **Улучшенная система сборки** - автоматическая пересборка EXE при создании MSI

- ✅ Улучшена система управления версией - синхронизация во всех файлах проекта
- ✅ Обновлены скрипты сборки - поддержка автоматического увеличения версии
- ✅ Улучшены сообщения в логах сборки для лучшей диагностики

### Исправлено

- ✅ Исправлена проблема с версией при сборке MSI - версия больше не увеличивается дважды
- ✅ Исправлены пути к ресурсам для MSI инсталлятора
