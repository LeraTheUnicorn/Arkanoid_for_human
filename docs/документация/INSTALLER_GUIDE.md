# Руководство по созданию инсталлятора

## 📋 Обзор

Этот документ содержит инструкции по созданию инсталлятора для игры Арканоид. Инсталлятор позволяет пользователям легко устанавливать игру без необходимости вручную устанавливать зависимости.

## 📦 Структура проекта

```bash
src1/
├── game/                      # Основной код игры
│   ├── PyGameBall.py          # Основной файл игры (точка входа)

│   ├── dirty_rects.py         # Система оптимизации отрисовки
│   ├── di_container.py        # Контейнер Dependency Injection
│   ├── highscores.py          # Система рекордов
│   ├── settings.py            # Настройки игры
│   └── version.py             # Версия игры
```

## 📋 Создание инсталлятора

### 1. Установка зависимостей

1. **Установите Poetry**:
   ```bash
   pip install poetry
   ```

2. **Установите зависимости**:
   ```bash
   poetry install
   ```

### 2. Сборка исполняемого файла

1. **Соберите исполняемый файл**:
   ```bash
   python scripts/build_exe.py
   ```

2. **Соберите MSI инсталлятор**:
   ```bash
   python scripts/build_msi.py
   ```

### 4. Тестирование инсталлятора

1. **Запустите инсталлятор**:
   ```bash
   Arkanoid_v2.3.161.exe
   ```

2. **Проверьте установку**:
   ```bash
   python -m pip list | findstr pygame  # Windows
   python -m pip list | grep pygame     # Linux/Mac
   ```

### 5. Создание релиза

1. **Создайте новый релиз на GitHub**:
   - Укажите версию
   - Добавьте описание изменений
   - Прикрепите исполняемые файлы

## 📋 Рекомендации

### Улучшение инсталлятора

- Используйте Poetry для управления зависимостями
- Включите все необходимые ресурсы в сборку
- Проверьте работу игры на чистой системе перед релизом

### Структура проекта

Проект использует модульную структуру с разделением на:
- **game/** - основной код игры с MVC архитектурой
- **resources/** - все игровые ресурсы
- **docs/** - документация проекта
- **scripts/** - скрипты для сборки

### Использование Poetry

Проект использует Poetry для управления зависимостями. Это обеспечивает:
- Воспроизводимые сборки
- Изоляцию зависимостей
- Простое управление версиями пакетов
